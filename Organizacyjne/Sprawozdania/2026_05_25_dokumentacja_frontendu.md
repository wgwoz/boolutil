# Sprawozdanie — Dokumentacja części frontendowej
**Data:** 25.05.2026
**Autor:** Maciej Karolak

## Opis zadania:
Zgodnie z nowym zgłoszeniem (Issue), przygotowano i wdrożono pełną dokumentację techniczną warstwy frontendowej projektu BOOLutil.

## Zakres prac:
* **Opis struktury:** Skatalogowano i wyjaśniono rolę plików `index.html` oraz `app.js`.
* **Dokumentacja komponentów:** Opisano działanie sekcji wprowadzania ręcznego oraz dynamicznego generatora tabeli prawdy.
* **Wykaz innowacji UX:** Szczegółowo udokumentowano wprowadzoną funkcjonalność cyklicznych przycisków wyników (`0` -> `1` -> `-`) oraz mechanizm agregacji danych dla API backendu.
* **Przepływ danych:** Zaimplementowano opis teoretyczny (Data Flow) ułatwiający przyszłą integrację z modułem w Pythonie.
